# AXON — Brand Site (v3)

سایت معرفی برند با اتمسفر سینمایی نسخه‌ی اول (موتور ذرات WebGL، ورود «نگه دار»، HUD فنی)
و روایت داستانی نسخه‌ی دوم. اسکرول خودِ تایم‌لاین داستان است: هر فصل روی صفحه می‌ماند، متن با محوشدن وارد و خارج می‌شود
و ذرات دقیقاً هم‌پای اسکرول از نماد یک فصل به نماد فصل بعد تبدیل می‌شوند. ساخته‌ها در یک ردیف افقی اسکرول می‌شوند.
نوار پیشرفت بالای صفحه است.

| فصل | پیام | شکل ذرات | پس‌زمینه |
|---|---|---|---|
| 00 دیروز | یک ایده، ده‌ها برنامه‌نویس، ماه‌ها انتظار. | جمعیت آدم‌ها `crowd` | `code` |
| 01 ورق برگشت | اون دوران ورق خورد. | پراکندگی `chaos` | — |
| 02 امروز | ایجنت‌های هوش مصنوعی وارد تیم شدن. | ربات `bot` | `network` |
| 03 سرعت | زمان کمتر، نتیجه‌ی بهتر. ماه‌ها ← هفته‌ها | صاعقه `zap` | `warp` |
| 04 ایده | هر جرقه‌ای… می‌تونه یه سایت/اپلیکیشن/… بشه. | لامپ `bulb` | `blueprint` |
| 05.x ساخته‌ها | صرافی، مارکت‌پلیس، فروشگاه، طلا، وکیل آنلاین | `bitcoin` `cart` `bag` `coins` `scales` | هرکدام جدا |
| 06 برند تو | برندت، ویترینی که دیده می‌شه. | صفحه‌ی لندینگ `landing` | `grid` |
| 07 اهلش | تو فقط ایده‌ت رو بیار؛ ساختنش رو بسپار به اهلش 😉 | مدارها `orbits` | — |
| 08 شروع | قصه‌ی بعدی، مال توئه. + تلگرام / واتس‌اپ / ایمیل / تماس | حلقه `ring` | `tunnel` |

## اجرا

```bash
node serve.mjs
```

سپس http://localhost:5173 را باز کنید. وابستگی نصبی ندارد (Three.js، GSAP و Lenis از CDN).

نسخه‌های قبلی: `node _v1/serve.mjs` (سینمایی اول) و `node _v2/serve.mjs` (داستان رنگی).

## فونت‌ها
Alexandria (تیترها)، Handjet (کلمات تأکیدی)، Vazirmatn (متن)، Martian Mono (برچسب‌ها).

## شخصی‌سازی
- **نام برند:** «آکسون / AXON» موقت است؛ در `index.html` جایگزین کنید.
- **تماس:** لینک‌ها و متن‌ها در بخش `#contact`، منو و فوتر `index.html`.
- **هر فصل** با ویژگی‌های `<section>` کنترل می‌شود: `data-shape`، `data-bg`، `data-theme`
  (`mint, violet, cyan, gold, ice, lime`)، `data-px` / `data-py` / `data-scale`، `data-align`، `data-valign`.
- **شکل جدید ذرات:** یک مسیر SVG به `ICONS` یا یک تابع به `SHAPES` در `assets/js/particles.js` اضافه کنید.
- **طول هر فصل:** ارتفاع  در  (پیش‌فرض 175vh) — بیشتر یعنی مکث طولانی‌تر روی هر صحنه.
- **سرعت اسکرول افقی:**  در .
- **پس‌زمینه‌ی جدید:** یک تابع صحنه در `assets/js/backdrop.js` و ثبت آن در `SCENES`.
